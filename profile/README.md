## open-wxa

**为微信小程序打造开放的开发与测试工具链。**

在普通浏览器里用微信官方基础库运行小程序：用 Chrome DevTools 调试，用 Playwright 做 E2E 测试、接入 CI，
还能部署到 Nginx 等静态托管上，发个链接别人就能打开。

**[文档](https://open-wxa.github.io/wxa-runner/)** · **[在线预览](https://wxa-viewer.picfinder.workers.dev)**

| 项目 | 说明 |
| --- | --- |
| [**wxa-runner**](https://github.com/open-wxa/wxa-runner) | 在浏览器中运行小程序，用于调试、E2E 测试和部署成静态网站 |
| [**wxa-extensions**](https://github.com/open-wxa/wxa-extensions) | 扩展与构建插件：元素检查器，uni-app 编译时自动启动 wxa-runner |
| [**wxa-baselib**](https://github.com/open-wxa/wxa-baselib) | 没有开发者工具时使用的微信官方基础库，版权归腾讯所有 |

欢迎提 Issue 和 PR，参与前请阅读[贡献指南](https://github.com/open-wxa/.github/blob/main/CONTRIBUTING.md)。
