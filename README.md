# open-wxa/.github

open-wxa 组织的公共配置仓库。

| 文件 | 作用 |
| --- | --- |
| [`profile/README.md`](./profile/README.md) | 显示在 [组织主页](https://github.com/open-wxa) 上的介绍 |
| [`CONTRIBUTING.md`](./CONTRIBUTING.md) | 贡献指南 |
| [`CODE_OF_CONDUCT.md`](./CODE_OF_CONDUCT.md) | 行为准则 |
| [`SECURITY.md`](./SECURITY.md) | 安全策略 |
| [`ISSUE_TEMPLATE/`](./ISSUE_TEMPLATE) | Issue 模板 |
| [`PULL_REQUEST_TEMPLATE.md`](./PULL_REQUEST_TEMPLATE.md) | PR 模板 |

除 `profile/` 外，这些文件是组织内所有仓库的**默认值**：仓库自身没有对应文件时，GitHub 会自动使用这里的版本。
